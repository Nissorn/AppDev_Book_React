# Book Management Application

A modern web application built with React and Vite for managing a book collection. Features a clean, responsive interface with smooth animations and real-time updates.

## Features

- Interactive book management interface
- Real-time table updates with smooth animations
- Modern UI with gradient backgrounds
- Responsive design with mobile support
- Clean and intuitive user experience

## Tech Stack

- React 18
- Vite
- TailwindCSS
- GSAP for animations
- Axios for API requests

## Getting Started

### Prerequisites

- Node.js (Latest LTS version recommended)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone [your-repository-url]
```

2. Install dependencies
```bash
cd book-app
npm install
```

3. Start the development server
```bash
npm run dev
```

### Building for Production

```bash
npm run build
```
